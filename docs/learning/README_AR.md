# دليل فهم مشروع Plugin ERP من الصفر

**نسخة دراسية مستقلة — 24 أكتوبر 2026**

الدليل ده معمول علشان تذاكر المشروع وتفهم ليه كل جزء موجود، حتى لو ما اشتغلتش أوتوميشن قبل كده. اقرأ الشرح بالترتيب أول مرة، وبعدها استخدم أطلس الملفات كمرجع وأنت فاتح الكود.

المشروع الموجود هنا **مش كود برنامج ERP نفسه**. هو مشروع بيختبر البرنامج عن طريق المتصفح، ومعاه تجهيز بيانات الاختبار والحسابات والتقارير. الفصل بين الاتنين أول معلومة لازم تثبت عندك.

## طريقة استخدام الدليل

1. أول قراءة: افهم الحكاية؛ مش مطلوب تحفظ أسماء الملفات كلها.
2. ثاني قراءة: افتح ملفين أو ثلاثة مع كل فصل، واتتبع المثال جوه الكود.
3. للمراجعة: افتح أطلس الفولدر، دور على اسم الملف، واقرأ دوره ومدخلاته وميثوداته المعلنة.
4. قبل التشغيل: راجع فصل التشغيل وحالة النسخة. الأمثلة الحية بتنشىء بيانات فعلية على Demo.
5. لو الكود اتغير: الكود وتعريفات التشغيل الحالية هما المرجع النهائي. الأعداد والصور الذهنية هنا لقطة بتاريخ النسخة، مش أرقام ثابتة للأبد.

## الدليل بيغطي إيه وما بيدّعيش إيه؟

بيشرح المصادر الحالية، ملفات الإعداد والتشغيل، تنظيم الاختبارات وملكية البيانات والتقارير. بيشرح كمان الملفات الفارغة أو المعلقة والملفات القديمة عشان ما تفتكرش إن كل اسم في المشروع شغال بالفعل.

مش دليل استخدام شامل لشاشات ERP للمحاسب، ومش مواصفات API رسمية للبرنامج، ومش وعد إن كل شاشة في ERP اتغطت. وجود اختبار في الكود غير تنفيذه بنجاح. وجود اسم ملف قديم غير إنه مستخدم في المجموعات الأساسية.

المصطلحات كلها مرتبطة بمثال من نفس المشروع. لو شفت كلمة جديدة، ارجع لجدول المصطلحات في الفصل الأول، وبعدها كمل؛ مش محتاج توقف المذاكرة لحد ما تتعلم Java كلها.

# أنواع المشاكل بشكل بسيط

التقرير يوضح ثلاثة أشياء منفصلة؛ التصنيف يساعدنا نراجع، لكنه لا يثبت وحده أن البرنامج فيه بج.

| نوع المشكلة | معناها | مثال |
|---|---|---|
| ضرائب وحسابات | مبلغ الضريبة أو الخصم أو التقريب مختلف | المفروض الضريبة5.25 وظهرت3 |
| مخزون وكميات | الكمية أو حركة المخزون غير المتوقعة | خصم الصنف مرتين |
| أرصدة وقيود وسداد | رصيد العميل أو الدفع أو القيد مختلف | فاتورة115 لم تظهر في المديونية |
| حفظ وتعديل وحذف | البيانات لم تُحفظ أو تغيّرت أو لم تُحذف | رجوع الاسم القديم بعد الحفظ |
| صلاحيات ودخول | الدخول أو السماح بالشاشة لا يطابق المطلوب | مستخدم يستطيع فتح شاشة ممنوعة |
| بحث وعرض البيانات | البحث أو ترتيب القائمة أو الفلتر مختلف | البحث يعرض صنفًا آخر |
| تقارير وطباعة | محتوى التقرير أو إجمالي الطباعة مختلف | كمية التقرير2 بدل1 |
| واجهة وتنسيق | تداخل العناصر أو ترتيبها ومحاذاتها | زر يغطي حقلًا |
| يحتاج تحديد | الأدلة لا تكفي لتحديد النوع | رسالة عامة دون خطوة واضحة |

## مصدر التوقف

- **شبكة أو بيئة التشغيل:** الاتصال انقطع أو السيرفر لم يرد. ده مش دليل على بج في الحسابات.
- **تنفيذ الاختبار:** مشكلة داخل كود الاختبار أو ملفاته. نراجع التست الأول.
- **تعذر إكمال خطوة:** الزر محجوب أو الشاشة لم تجهز في الوقت. نراجع الصورة والانتظار والبرنامج.
- **مقارنة النتيجة:** التست وصل للنتيجة، لكن القيمة اختلفت. نراجع المتوقع والفعلي.

## معروفة ولا جديدة؟

- **مشكلة معروفة:** رسالة الفشل تحتوي رقمًا موثقًا بصيغة `KNOWN_BUG:ERP-17`؛ لا نعتبر أي فشل في نفس الشاشة هو نفس البج.
- **فشل يحتاج مراجعة:** ظهر اختلاف لم يرتبط برقم موثق؛ قد يكون بج أو توقعًا يحتاج تصحيحًا.
- **الحالة لم تُنفذ:** Ignore/Skip؛ نراجع التجهيز أولًا ولا نسجلها كبج جديد.

## المشاكل المثبتة حاليًا

| المشكلة | النوع | ما ثبت |
|---|---|---|
| مرتجع الإضافية | ضرائب وحسابات | مرتجع وحدة ظهر23 بدل40.25 |
| التقريب المبكر | ضرائب وحسابات | بيع عام ظهر28.80 بدل28.79 |
| المتبقي في العقد | مخزون وكميات / متابعة الفوترة | التحويل مرة أخرى لم يعرض المتبقي الصحيح |
| إعادة فتح تحت الإجراء للخرسانة | حفظ وتعديل وحذف / عرض الشاشة | البيانات محملة لكن الحقول المعروضة فارغة |
| Ignore في رن المطاعم | شبكة وتجهيز | الاتصال ثم تجهيز الدخول فشلا؛ الحالات الثلاث لم تُنفذ |

التفاصيل والأدلة في [سجل المشاكل](KNOWN_BUSINESS_ISSUES.md). أرقام الحالات الداخلية مثل REST-RETURN-001 ليست تذاكر خارجية، ولا تتحول تلقائيًا إلى «مشكلة معروفة» في تقرير كل رن.

حجم الضرر مختلف عن نوع المشكلة: خطأ مبلغ أو ضياع بيانات مهم، وتوقف التشغيل مهم، واختلاف لون أو ترتيب قد يكون أقل. لم نضع درجة خطورة آلية اعتمادًا على كلمات الخطأ وحدها.

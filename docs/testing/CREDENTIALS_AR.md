# إعداد بيانات الدخول

ملف `src/main/resources/Login.properties` يحتوي أسماء المفاتيح فقط، دون بيانات دخول.
الإعدادات الحالية محفوظة محليًا في `config/Login.local.properties`، وهو ملف يتجاهله Git ولا يُنسخ ضمن موارد Maven.

على جهاز جديد، انسخ ملف المفاتيح إلى `config/Login.local.properties` ثم املأ قيم البيئة التي ستشغّل عليها الاختبارات.

يمكن توفير القيم في بيئة CI عبر متغيرات البيئة: يتحول المفتاح `Demo.Password` إلى `ERP_DEMO_PASSWORD`، والمفتاح `Demo.Username` إلى `ERP_DEMO_USERNAME`. الأولوية: معاملات Java `-D` ثم متغيرات البيئة ثم الملف المحلي ثم الموارد الافتراضية. يُفضّل الملف المحلي أو متغيرات البيئة للأسرار لتجنب ظهورها في سجل أوامر الطرفية.

خطوة تسجيل الدخول لا تضيف كلمة المرور إلى معاملات Allure، وأداة الكتابة تحجب قيمة حقول `type=password` من السجل ورسائل عدم تطابق القيمة.

إزالة القيم من النسخة الحالية لا تزيلها من تاريخ Git أو التقارير القديمة. يجب تغيير كلمات المرور التي سبق حفظها أو مشاركة تقارير تحتوي عليها؛ لم يُعدّل تاريخ Git ضمن هذه الخطوة.

# الملفات التي تم فرزها

## ملفات الشاشات

شرح عربي بسيط في أول553 ملف Java، منها151 ملفًا للشاشات ومساعداتها في `System_Modules`: ما الشاشة أو المهمة التي يخدمها وفائدتها. ملفات المساعدة مطلوبة للشاشات؛ ليست ملفات زائدة لمجرد أنها لا تفتح شاشة وحدها.

## أدوات احتفظنا بها وكتبنا فائدتها

| الملف | فائدته |
|---|---|
| add_report_charts.py | إضافة رسوم لتصميم تقرير المبيعات |
| upgrade_sales.py | تجهيز أشكال مختلفة لتقرير المبيعات |
| repair_executive.py | إصلاح شكل النسخة التنفيذية من التقرير |
| style_invoice.py | تنسيق شكل الفاتورة المطبوعة |
| chart-template.xml وms-chart-reference.rdl وinvoice-reference.png | مراجع لتعديل تصميم التقارير |
| .report-format | أدوات ونتائج تنسيق تقرير Word سابق |

هذه أدوات يدوية موثقة في دليل المشروع؛ ليست مطلوبة في كل رن لكن حذفها يفقد وظيفة مستخدمة.

## ملفات مؤقتة يمكن الاستغناء عنها

- `scripts/__pycache__`: ملفات يعيد Python إنشاءها؛ ليست كود المشروع.
- `hs_err_pid*.log` و`replay_pid*.log` في جذر المشروع: سجلات أعطال Java القديمة؛ ليست لازمة لتشغيل المشروع، وتفيد فقط في تشخيص تلك الأعطال.

محاولة حذفها تلقائيًا رفضتها سياسة الأداة في هذه الجلسة؛ لذلك لم تُحذف.

## ملفات لم نحذفها

لم نحذف سجلات استرجاع بيانات الاختبارات، أو إعدادات الدخول، أو أدوات التشغيل، أو نتائج المستخدم، أو مجلد target بالكامل. هذه المجلدات مختلطة وفيها بيانات استرجاع وأدلة واختبارات حديثة، وكان IntelliJ وعمليات Java مفتوحين وقت الفرز. لا يوجد ملف كود ثبت أنه بلا استخدام يستحق حذفه في هذا الفرز.

توسعة الشرح: التعليقات موجودة الآن في جميع ملفات Java وفي127 ملف تشغيل وإعدادات وسكربت. ملفات البيانات والصور والأرشيفات لها تعريف داخل `شرح_الملفات.md` في نفس المجلد، دون إدخال نص يكسر صيغتها.

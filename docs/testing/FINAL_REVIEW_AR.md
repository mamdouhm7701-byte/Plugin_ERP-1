# مراجعة إغلاق تنظيم إطار الاختبارات — 21 أكتوبر 2026

اكتملت أعمال فصل المسؤوليات المخططة في تجهيز بيانات الوحدات، وتنظيم اتصال المتصفح ومحاكاته، وقوائم المبيعات والمشتريات والتقويم، والتفاعلات المشتركة للنماذج. بقاء كلاس كبير لا يبرر تقسيمه تلقائيًا؛ تبقى إدارة الملكية والاستعادة والتنظيف المرتبط بعضها ببعض داخل مالك البيانات، وتبقى تأكيدات قواعد العمل داخل الاختبارات.

## تشغيل موحد

```powershell
./scripts/Test-Project.ps1                 # فحوص محلية فقط
./scripts/Test-Project.ps1 -Mode Acceptance # محلي ثم الدخول وSmoke
./scripts/Test-Project.ps1 -Mode Regression # محلي ثم Regression الحي
```

يسجل كل تشغيل نتائج Allure الخام ونسخ تقارير Surefire وسجلات Maven في مجلد مستقل تحت `target/validation/<run-id>`. يتوقف قبل التشغيل الحي عند فشل المحلي، ويعيد فشلًا إلى الطرفية عند فشل أي مرحلة. يعمل من أي مجلد لأن جذر المشروع يُستنتج من موقع السكربت. لا يستخدم `mvn clean` ولا يحذف السجلات التاريخية. تُشغّل الأوامر تباعًا في نسخة العمل نفسها.

## التحقق النهائي المنفذ

نجحت **386 حالة محلية دون فشل أو تخطٍ**، بما فيها صحة ملفات التحقق الجديدة وملف القبول المركّب. فُحصت مراجع 30 ملف TestNG دون مراجع مفقودة، ولم توجد مسارات نتائج أو مكتبات محمّلة أو `config/Login.local.properties` ضمن ملفات Git المتتبعة في الفحص.

بعد إغلاق التنظيم، اكتملت نقطة رقم 4 من التقييم: [مراجعة أدوات التحقق القديمة](LEGACY_ASSERTIONS_AR.md). أُصلحت دلالة الظهور وعزل التحقق المرن، وأصبحت نتيجة CI المحلية الأحدث **396 حالة ناجحة دون فشل أو تخطٍ**. نتيجة القبول الحي أدناه تخص إغلاق التنظيم السابق، ولم يُعَد تشغيلها لهذا المسار غير المستخدم في الصفحات.

نجح القبول الحي النهائي في **11 حالة دون فشل أو تخطٍ**: الدخول الصحيح ورفض حساب غير موجود، ثم تسع عمليات Smoke عبر الوحدات الأساسية. اكتمل إعداد وتنظيف الكلاسات، وأصبحت **18 سجلًا** للبيانات والمحاولات وسجلات صفحة العملاء الخاصة بالتشغيل فارغة. لم تُحذف السجلات التاريخية.

الأدلة المحلية تحت `target/validation/3b2fcfc18e284fb08323c086f6244021`: سجلا `local.log` و`live.log`، ونتائج Allure الخام، ونسخ Surefire، و`live-journal-check.json`. فحص الملفات في `target/final-project-audit.json`. نجح أمر القبول الموحد وأعاد exit code صفرًا.

## حدود الإغلاق

هذه مراجعة لإطار الاختبارات الموجود في المستودع. كود واجهة ERP وخادمه غير موجود هنا؛ إصلاح عيوب أعمال التطبيق يتطلب مستودعاته. عيوب الأسعار والتصدير في [الأصناف](../../src/test/java/ProductsTest/KNOWN_BUGS.md)، ورصيد أمر البيع النقدي في [المبيعات](../sales/KNOWN_BUGS.md)، والكميات والمرتجعات وأمر الشراء النقدي في [المشتريات](../purchases/KNOWN_BUGS.md) تبقى موثقة باختبارات مفعلة. هذه تقارير سابقة وليست ادعاء بإعادة إثبات كل عيب في تشغيل الإغلاق.

تشغيل القبول يشمل الدخول وعمليات Smoke الأساسية عبر الوحدات، ولا يحل محل Regression الكامل أو إثبات كل حدود قواعد العمل والتصدير والطباعة. تشغيل GitHub/Ubuntu المستضاف يحتاج رفع التغييرات؛ الفحوص المنفذة هنا محلية على Windows. لم يُنفذ نشر أو رفع أو تعديل لبيانات اعتماد المستخدم.

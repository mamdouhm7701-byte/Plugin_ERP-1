# تنظيف تتبع الملفات في Git

نُفذت هذه الخطوة دون تغيير كود Java أو أسماء الاختبارات أو ملفات تشغيلها أو بياناتها، ودون نقل الملفات المحلية أو حذفها.

أزيل من الفهرس باستخدام `git rm --cached` عدد **8,957 ملفًا**:

| المجموعة | السبب |
| --- | --- |
| `outputs/erp-arabic-20261019/work/node_modules` | مكتبات Node محمّلة؛ المسار المحلي وصلة إلى مكتبات بيئة إنشاء المستندات |
| `allure-cli` | أداة محمّلة يمكن للكود تنزيلها عند الحاجة |
| `test-outputs` | سجلات تشغيل محلية |
| `.idea` | إعدادات IntelliJ الخاصة بالجهاز |

كل الملفات المحلية الـ8,957 ظلت موجودة بعد العملية. تمت مقارنة SHA-256 لعدد 386 ملفًا من الكود والإعدادات والتوثيق ومخرجات المستندات خارج node_modules، ولم يتغير أي منها. ظلت ملفات Word وExcel وPDF وسكربتات إنشائها ومصادر محتواها متتبعة كما كانت.

نُظّم `.gitignore` لإزالة التكرار ومنع تتبع هذه المجلدات مرة أخرى، مع الحفاظ على قواعد البناء وملف كلمات المرور المحلي. أضيف تجاهل فيديوهات التشغيل. لم يُعدّل تاريخ Git؛ الأحجام السابقة تظل في التاريخ.

تظهر إزالة التتبع في Git كحذف مجهز في الفهرس، لكن الملفات على القرص باقية. هذه طريقة Git لإخراج ملف من النسخ المقبلة؛ لا تعني حذفه محليًا. لا تتضمن هذه الخطوة commit أو push.

لم تُقسّم الكلاسات الكبيرة ضمن تنظيف المستودع. فصل كود تجهيز البيانات أو تنظيفها يحتاج تغييرًا مستقلاً واختبارات خاصة بترتيب التبعيات وملكية السجلات، حتى لا تختلط إعادة الهيكلة بإزالة المكتبات والسجلات من التتبع.

أدلة الحفاظ على الملفات محلية داخل `target/repository-*.json` و`target/repository-*.txt`. لا تُضاف هذه النواتج إلى Git.

## التحقق بعد التنظيف

صُدّرت الملفات المتتبعة من الفهرس باستخدام `git checkout-index` إلى `target/repository-clean-check`، دون node_modules أو Allure CLI أو بيانات الدخول المحلية. نجح بناء المشروع من هذه النسخة، ونجحت **254 حالة اختبار محلية دون فشل أو تخطٍ**. استخدم البناء JDK 21 وذاكرة Maven المحلية للمكتبات؛ الاختبارات المختارة لا تتصل بـERP. الدليل في `target/repository-clean-check-build.log`.

لم يتبق أي ملف متتبع يطابق قواعد التجاهل، ولم يُزل من الفهرس أي مسار خارج قائمة الملفات المحددة للتنظيف. ملفات الكود وإعدادات Maven وTestNG كما كانت؛ التغييرات النصية تخص `.gitignore` ودليلي التوثيق الجديدين فقط.

# التغطية والوقت من نتائج فعلية

هذا الملف يشرح تقرير ربط الحالات بشاشات النشاط وقياس الوقت دون تغيير النتيجة الأصلية.

```powershell
python -X utf8 scripts/build_run_evidence.py allure-results target/run-evidence
```

افتح `target/run-evidence/run-evidence.html`. يقبل الأمر مجلد نتائج آخر بدل `allure-results`.
كل تقرير يخص مجلد نتائج واحدًا؛ لا تخلط جولات مختلفة أو مجلدات CI والبيزنس.

التقرير يعرض:

- الحالات المرتبطة بنشاط وشاشة، مع حالتها وإعدادات الفرع ورابط النتيجة الأصلية.
- الحالات التي لا تحمل نشاطًا موثقًا؛ لا ينسبها تلقائيًا إلى نشاط من اسم الكلاس.
- أبطأ الكلاسات حسب وقت العمل المسجل، مع فصل التجهيز والتنفيذ والتنظيف.
- مدة اتحاد فترات التنفيذ، والمدة من أول حدث لآخر حدث مسجل، وعدد أخطاء التجهيز والتنظيف.

نجاح كلاس ليس إثبات اكتمال شاشة. الربط على مستوى الكلاس دليل جزئي، وقد تستخدم
حالات نفس الكلاس مسارات مختلفة. الحالات الموروثة تستخدم اسم كلاس التنفيذ من
`testClass` عند توفره؛ بدونه قد تبقى بلا ربط إن نسبها التقرير للأب.
ماتريكس التغطية الأصلية لا تُرفع إلى مكتملة بسبب هذا التقرير.

المدد المتوازية لا تُجمع كأنها مدة الرن. وقت البناء وتجهيز الفرع وتنظيفه خارج تسجيل
Allure ليس جزءًا من هذا القياس. رابط الدليل يتبع المجلد الأصلي؛ أرشفه قبل الرن التالي.
التقرير على رن جارٍ لقطة مؤقتة، ولا يثبت انتهاء الاختيار أو نجاح التنظيف.

اختيار عدد المتصفحات يعتمد السعة وحالات العزل المعتمدة. لا يغير التقرير قائمة التوازي
تلقائيًا؛ نحتاج مقارنة نفس المجموعة على نفس الإعداد بعد معالجة عائق السعة.

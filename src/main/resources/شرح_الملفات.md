# شرح ملفات هذا المجلد

هذه الملفات بيانات أو صور أو نتائج محفوظة. صيغتها لا تقبل تعليقًا عاديًا في أولها؛ لذلك التعريف هنا بجانبها حتى تظل قابلة للقراءة والتشغيل.

| الملف | هو إيه وليه موجود؟ |
|---|---|
| [issue-register.json](issue-register.json) | متابعة العيوب وقواعدها وتذاكرها وإصدار الإصلاح وإعادة الاختبار؛ لا يغلق العيب تلقائيًا |
| [allure-case-descriptions-business.json](allure-case-descriptions-business.json) | شرح حالات الأنشطة والضرائب والإضافية والعقود والخرسانة الجديدة |
| [allure-case-descriptions-master.json](allure-case-descriptions-master.json) | شرح حالات البيانات الأساسية والأصناف، وخطواتها ونتائجها المطلوبة |
| [allure-case-descriptions-remaining.json](allure-case-descriptions-remaining.json) | شرح بقية الشاشات والحالات بالتفصيل البسيط |
| [allure-case-descriptions-transactions.json](allure-case-descriptions-transactions.json) | شرح حالات البيع والشراء والحركات المرتبطة بهما |
| [allure-categories.json](allure-categories.json) | أسماء مجموعات الفشل في التقرير وشروط اعتبار المشكلة معروفة أو جديدة |
